## Golden rules
1. `:core` is pure Kotlin/JVM. **Never add `android.*` imports there.** New pure logic goes in `:core` with unit tests.
2. UI talks to the AI only through `AiEngine` (never providers/HTTP directly).
3. Never hand-edit `core/.../prompt/DefaultPromptsData.kt` (generated by `tools/generate_default_prompts.py`).
4. Follow `design/stitch/editorial_precision/DESIGN.md` + `docs/DESIGN_NOTES.md`. Never render invented mock text. No emoji icons.
5. Never put real API keys in code, tests, logs, or anything exported.
6. Make small changes; after each one run `./gradlew :core:test` (and a build when UI changed). Don't rewrite files that already work.
7. If something in the docs contradicts what the compiler/IDE tells you, trust the compiler and update the docs.
